Quick Guide — How to Use This Site

This tool lets you load your own MCQs, take a timed test, review answers, use NotebookLM prompts, and study your reports. Use the section below as a quick start guide.

Select Single MCQs for 1-mark questions or Case-based MCQs for 2-mark scenario questions.
2

Paste or Load Questions

Paste your questions in the required format, or click Load 5 Sample Questions to test the tool instantly.
3

Start and Attempt

Review Reports & AI Prompts

After submission, review score, charts, time reports, and if needed scroll further down to use the AI Prompts for Question Generation section.

Standard MCQ Prompt

You are a CA Final exam paper setter working under ICAI standards. I am uploading [study material / an MCQ booklet chapter]. Your task is: ► If it is an MCQ booklet → EXTRACT all MCQs exactly as-is, correcting any formatting errors, and output them in the required format below. ► If it is study material → GENERATE original MCQs from the content. ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ DIFFICULTY & QUALITY STANDARDS ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ - CA Final level only — test conceptual application, judgment, and computation; never rote recall - Distractors must be plausible and drawn from common misconceptions or similar-sounding provisions - Language: ICAI Final exam style — formal, precise, unambiguous - Each question must be self-contained and independently answerable - No duplicate or near-duplicate questions - Skip any question that is incomplete, ambiguous, or sub-Final level ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ ANSWER POSITION SHUFFLING (MANDATORY) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ Before writing a single question, privately assign a random answer position sequence for the full set (A/B/C/D), such that: - Each letter appears approximately 25% of the time across the full set - There is no pattern: no cycling (A,B,C,D,A,B...), no pairing, no front-loading - The correct option MUST land at the pre-assigned position — BUILD the question around the position, not the other way around - Never let the naturally correct position override the shuffled assignment ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ OUTPUT FORMAT — STRICT ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ Output ONLY a plain pipe-separated table. Case-Based MCQ Prompt
For generating scenario-based questions from study material
You are a CA Final exam paper setter specialising in case-based MCQs under ICAI standards. I am uploading study material. GENERATE high-quality case-based MCQs. ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ CASE SCENARIO QUALITY STANDARDS ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ - Each case must read like a real professional scenario — a company, entity, or fact pattern with specific named figures, dates, amounts, and context - Scenarios must be rich enough that multiple concepts or computations can be tested from a single case - Avoid generic, textbook-sounding scenarios (Company A did XYZ) — use realistic industry-specific details - CA Final level only — questions must require application, analysis, or judgment, not recall - Language: ICAI Final exam style — formal, precise, no ambiguity - Each individual MCQ must be answerable using the case scenario alone ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ PERMITTED CASE STRUCTURES ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ STRUCTURE 1 — One case, 2–5 MCQs: Write one detailed scenario (5–8 lines), then derive 2–5 questions each testing a different concept, sub-section, or computation from that same case. STRUCTURE 2 — One case, 1 MCQ: Write a concise scenario (3–4 lines) with a single focused question testing one key concept. Use a healthy mix of both structures across your output. ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ ANSWER POSITION SHUFFLING (MANDATORY) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ Before writing anything, privately assign a random answer-position sequence (A/B/C/D) for all MCQs across all cases, such that: - Each letter appears approximately 25% of the time - No pattern: no cycling, alternating, pairing, or front-loading - Build each question so the correct option lands at the pre-assigned position — position drives construction, not content ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ OUTPUT FORMAT — STRICT ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ Output ONLY a plain pipe-separated table. Nothing else — no headings, no explanations, no blank rows.
